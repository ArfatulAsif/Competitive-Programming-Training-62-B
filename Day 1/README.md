# Getting Started with Competitive Programming

## 1. Create Accounts on Online Judges

Create an account on each of the following Online Judge (OJ) platforms:

-   **Codeforces**
-   **CSES**
-   **AtCoder**
-   **CodeChef**
-   **LightOJ**
-   **VJudge**

> **Important:** Use your Metropolitan University ID in the following format as your **Username/ID Name**:
> 
> `251-115-nnn`

Make sure to use the same ID consistently across all platforms.

----------

## 2. Set Up the Programming Environment

We will use the following tools for solving competitive programming problems:

-   **IDE:** Visual Studio Code (VS Code)
-   **Programming Language:** C++

Make sure your VS Code environment is properly configured for compiling and running C++ programs.

----------

## 3. AI Usage Policy

> **AI usage is strictly prohibited.**

The use of AI tools for solving competitive programming problems is **completely prohibited**.

If anyone is found using AI during problem-solving or contests, they will **not be considered under any circumstances**.

----------

## 4. Let's Solve Our First Problem

Now that our accounts and programming environment are ready, we will solve our **first competitive programming problem**.

We will use **VJudge** to understand:

-   How competitive programming contests are conducted
-   How to submit solutions
-   How submissions are evaluated
-   How to interpret verdicts
-   How to participate in a contest
