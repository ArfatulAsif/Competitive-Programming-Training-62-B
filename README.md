# Competitive-Programming-Training-62-B

# Join Vjudge Group: https://vjudge.net/group/mu62b



# Our possible Lab Schedule:

| Lab Session | Core Focus | Specific Topics Covered | Marathon Contest Theme |
| --- | --- | --- | --- |
| **Lab 1** | **Foundations & Basic STL** | Vjudge introduction, verdicts (AC, WA, TLE), Auto, Pair, Vector syntax, for-each loops, and handling test cases. | Ad-hoc problem solving and basic variable manipulation. |
| **Lab 2** | **Vector Deep-Dive** | Subarrays, subsequences, reversing vectors, array sums, max/min frequencies, and solving with vectors of integers. TIME and Space Complexity. | 1D array manipulation and brute-force simulations. |
| **Lab 3** | **Strings & 2D Processing** | Strings, substrings, palindrome checking, vector of strings, and multidimensional arrays (2D grids). | String formatting, character counting, and grid traversal. |
| **Lab 4** | **Advanced STL & Complexity** | Sets, Maps (including unordered variants), STL SORT Function, and calculating Time/Space Complexity. | Optimizing lookups, frequency mapping, and distinct elements. |
| **Lab 5** | **Number Theory Basics** |  Primes, Primality Detection, Sieve of Eratosthenes, GCD, LCM, and counting divisors. | Mathematical efficiency and avoiding brute-force math loops. |
| **Lab 6** | **Prefix Sums** | 1D Prefix Sum arrays, pre-computation logic, and handling multiple range queries efficiently. | Range sum queries and defeating Time Limit Exceeded (TLE) verdicts. |
| **Lab 7** | **Linear Data Structures** | Stack, Queue, Priority Queue, and understanding Last-In-First-Out (LIFO) vs. First-In-First-Out (FIFO). | Simulating queues, parenthesis balancing, and tracking dynamic maximums. |
